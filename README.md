# 🤟 AI Sign Language Detection

## 🚀 Project Overview

AI Sign Language Detection  YOLOv5 is an AI-powered accessibility solution designed to bridge the communication gap between sign language users and non-sign language users.

The system uses a custom-trained YOLOv5 object detection model to recognize sign language gestures in real time through webcam input and convert them into readable text output.

This project combines:

* Computer Vision
* Deep Learning
* Real-time Detection
* Full Stack Development
* Accessibility-focused AI

Built for **HACKHAZARDS '26**.

# 🧠 Inspiration

Millions of people around the world rely on sign language for communication, but communication barriers still exist in educational, professional, and public environments.

I wanted to create a smart AI-powered system capable of translating sign language into text in real time, making communication more inclusive and accessible.

---

# ❗ Problem Statement

People using sign language often face difficulty communicating with those unfamiliar with sign language.

Traditional communication methods may:

* require interpreters
* lack accessibility
* be expensive
* fail in real-time interactions

This project aims to solve these challenges using AI and Computer Vision.

---

# 💡 Solution

Our system:

* captures live webcam input
* detects hand gestures using YOLOv5
* predicts sign language characters/gestures
* converts predictions into readable text
* generates output for communication

The platform provides a scalable and intelligent accessibility solution powered by AI.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Ankana-Sadhukhan/AI-Sign-Language-Detection-YOLOv5.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd AI-Sign-Language-Detection-YOLOv5
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run Detection System

```bash
python run.py
```

---

# 🧪 Model Training

Train custom YOLOv5 model:

```bash
python train.py --img 416 --batch 16 --epochs 50 --data dataset.yaml --weights yolov5s.pt
```
